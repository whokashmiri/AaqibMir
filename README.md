# React + Vite + Three.js Portfolio

## Stack
- React JS
- Vite
- Tailwind CSS
- React Three Fiber
- Drei
- Framer Motion
- GSAP
- Three.js

## Install
npm install

## Run
npm run dev

## Build
npm run build

## Folder Structure

src/
  components/
    canvas/
    common/
    sections/
    ui/
  constants/
  hooks/
  lib/
  utils/
  styles/

public/
  models/
  textures/

## Add GLB Models

Put models here:

public/models

Example:

public/models/laptop.glb
